# 단계별 인계 기록

최종 파일: output/id_ctrl_ko.html

편집 원본: source/catalog.json. Python 과거 편집 모듈은 이관 기록이며 현재 빌더의 원본이 아닙니다.

## 1단계

전체 152개 범위 대응 등록. 고유 조건 231개. 원문 대조 완료 필드 2개.
남은 의미 대조·예외 확인은 상태로 표시합니다. 등록 완료를 내용 확인 완료라고 표시하지 않습니다.

## 2단계

세 탭·직접 관계도/표·역방향 탐색·조건 링크·공통 적용 설정을 제공합니다.

## 3단계

여섯 작업 화면은 고정 조건 ID를 참조합니다. 자료 목록·순서·조건·미확인 사항·CSV/인쇄·단위 예제를 제공합니다.

## 4단계

JSON 프로젝트, 관측 대상과 시점, 파일명·메모, 결과·검토자, 변경 이력, revision 재확인 및 삭제 조건 보존을 제공합니다.

## 검증

test_catalog.py: 고정 ID/순서 변경/의무 수준 변경/원문 누락/PSD 독립 대상 검사.
enhancement_qa.cjs: 오프라인 전체 화면·직접 링크·6개 작업·잘못된 JSON·저장/복원·이력·개정/삭제·CSV·모바일 검사.

## 재생성

python build.py

## 남은 외부 근거

IEEE OUI CSV 서버는 HTTP 418로 거절했습니다. source/external_manifest.json에 시도 결과를 기록했습니다. 미조회 값을 미할당으로 판정하지 않습니다.
다른 Command Set·보안 인증·고객 자료와 원문 불일치는 후속 확인 목록에 남습니다.
